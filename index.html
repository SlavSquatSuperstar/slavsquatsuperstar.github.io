Software Analysis Research Project

  • Category: Software Testing
  • Summary: The final research project for my Software Analysis course. Null safety is an important topic in Java, since Java is a highly object-oriented language and contains no good built-in features to communicate nullability. I analyzed true and false positive warnings produced by NullAway and JSpecify, two static analysis tools for Java compared to out-of-the-box IDE features. I concluded that, with proper annotation, the analyzer uncovered genuine null-pointer faults and minimized new false positives while also better documenting developer intent.
 Source Code Report Included

Security Testing Research Project

  • Category: Software Testing, Cybersecurity
  • Summary: The final research project for my Security Testing course. Fuzz4All (Xia et al., 2024) is a universal fuzzer that uses LLMs to generate fuzzing inputs for any programming language, formal language, or complex grammar. I extend the study to use more recent models and reproduce the paper's experiments and figures. I discovered newer models (especially reasoning LLMs) achieved up to 35% less coverage than the baseline due to producing too few outputs to sufficiently cover enough paths.
